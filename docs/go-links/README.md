# 動画から売り場への短いリンク `/go/<コード>`

社長の決定 D-068①・D-070①。動画の説明欄には売り場の URL をじかに書かず、この短いリンクだけを書く。

- 形: `https://www.ai-compass-journal.com/go/<キット>-<売り場>-<動画>`(例 `/go/jcv-booth-m10`)
- 売り場は `booth` `unity` `fab` のどれか。コードは小文字・数字・ハイフンだけ。

## 飛び先を替える

`src/data/goLinks.json` の `to` だけを替える(コードは変えない。数が続くように)。

- `to` に書けるのは、ホームページ内のパス(`/` で始まる)か、BOOTH・Unity Asset Store・Fab の `https://` の URL だけ。
- 替えたら `npm run validate-go-links` で確かめる。
- 表に無いコードは 404 になる。

## 数えるもの

飛ぶ前に1回数える。残すのは **日付(日本時間)・コード・回数だけ**。クッキー・IP・ブラウザの情報は残さない。
リンクの下見をするロボット(SNS のプレビューなど)は数えない(見分けるだけで、残さない)。

数はつぎのところに出る:

1. **Vercel Web Analytics**(サイトにもう入っている。クッキーを使わない)。ページ別の数で `/go/...` を見る。新しい設定は要らない。
2. **Vercel のログ**: 1回ごとに `{"event":"go_hit","date":"...","code":"..."}` の1行(残る期間は短い)。
3. **(入れるなら)Upstash Redis**: Vercel の Marketplace から Upstash Redis(無料の枠)をつなぐと、`go:<日付>` に コードごとの数が自動で入る。コードの変更は要らない。
4. **手元の確かめ用**: `GO_COUNT_FILE=<JSON のパス>` をつけて `npm run dev` すると、そのファイルに日付ごと・コードごとの数が入る。
