# Distribution UTM and Posting Checklist

Status: `PREPARED / NO_EXTERNAL_POST`

## Naming

- `utm_source`: `note` or `x`
- `utm_medium`: `organic_social`
- `utm_campaign`: `notta_evidence_pilot`
- `utm_content`: controlled post identifier such as `note_digest_v1`

Never put account IDs, personal data, free text, affiliate destinations, or provider tracking parameters into analytics events.

## Human posting gate

- Evidence and screenshots approved
- Advertising disclosure approved
- Final public URL approved
- No private dashboard or tracking URL visible
- Mobile preview checked
- Link destination checked
- UTM values use the controlled vocabulary
- Human explicitly approves posting

Codex must not post automatically.
